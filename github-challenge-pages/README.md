# MetaCricket challenge links (GitHub Pages)

WhatsApp can tap this https page. The page then opens the MetaCricket app.

## Upload (once)

1. On GitHub: New repository → name it `metacricket-challenge` → Public.
2. Upload every file in this folder (keep the `challenge` and `.well-known` folders).
3. Repo → Settings → Pages → Branch: `main` → Folder: `/ (root)` → Save.
4. After 1 minute the link is:

`https://YOUR_GITHUB_USERNAME.github.io/metacricket-challenge/challenge/?score=15&cid=testdemo&from=someoneelse&name=Test&balls=12`

5. Put that username in `ChallengerDeepLink.GitHubPagesUser` in Unity.

## Test

Open that https link on the **phone** (WhatsApp or Chrome).  
A new MetaCricket APK from this project must already be installed.
